# Contributing

Everyone may fork, use, and modify this public repository under its LICENSE.
Open issues and pull requests against this fork's main branch for changes to
the fork. Upstream contributions can also be sent to the
[upstream project](https://github.com/sgl-project/sglang).

Follow the project's existing development instructions, style, and relevant
tests. Describe the change and the checks performed in the pull request.
Preserve upstream attribution and bundled third-party licenses. Do not commit
credentials, private datasets, or generated deployment secrets.

Follow CODE_OF_CONDUCT.md. Use SECURITY.md for private vulnerability reporting,
not the public issue tracker.
